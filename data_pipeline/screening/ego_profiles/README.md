# Ego screening profiles

These JSON profiles hold alternative quality checks for screening the verified Ego pool (`support50_v3`, `speedp95_v3`, `moderate4_residual_v1`, `relaxed6_soft`). Select one through the `--config` option of [screen_ego.py](../screen_ego.py); the [screening guide](../README.md) describes the default profile (`ego_qc.json`).
